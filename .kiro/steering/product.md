# Product Overview

**lst97.dev** is a personal website and portfolio built as a modern, interactive showcase with pixel art aesthetics and retro gaming inspiration.

## Core Features

- **Personal Portfolio**: Professional showcase with project galleries, tech stack visualization, and career timeline
- **Interactive Guest Book**: Digital visitor system with comment moderation and spam protection
- **Uber Delivery Portfolio**: Professional delivery service showcase with customer review system
- **AI Terminal Chat Bot (Nelson)**: Interactive AI assistant with terminal interface for portfolio inquiries
- **Content Management**: Headless CMS powered by PayloadCMS for blog posts and dynamic content
- **Developer Tools**: Various utility tools including background remover, file type detector, and image converter

## Design Philosophy

- **Pixel Art Aesthetic**: Retro gaming-inspired design with custom pixel art assets
- **Terminal Interface**: Command-line style interactions for technical authenticity
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **Accessibility**: WCAG compliant with proper semantic markup
- **Performance**: Optimized images, lazy loading, and efficient bundling

## Target Audience

- Potential employers and clients
- Fellow developers and tech enthusiasts
- Delivery service customers (Uber portfolio)
- General visitors interested in interactive web experiences
